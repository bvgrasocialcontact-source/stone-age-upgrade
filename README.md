# Stone Age Upgrade — Kanal Klasörü

Bu klasörün düzeni:

- 00_brand/        Logo, renk paleti, fontlar, thumbnail şablonları, kanal görselleri
- 01_episodes/     Her bölüm kendi klasöründe (EP01_Claude, EP02_..., ...)
- 02_library/      Tekrar kullanılan çizimler: karakter (You), arka planlar, hayvanlar, objeler, müzik/efekt
- 03_engine/       Animasyon motorunun kaynak kodu (yedek)
- 04_publishing/   Açıklama, etiket ve sabit yorum şablonları; yayın takvimi

Bir bölüm klasörünün içi:
- 01_script/     Senaryo, etki haritası, plan listesi
- 02_audio/      ElevenLabs anlatım sesi BURAYA (.mp3 veya .wav) + varsa ElevenLabs zaman damgası (.srt/.json)
- 03_assets/     Bölüme özel çizimler ve temsili görseller (kaynak notlarıyla)
- 04_renders/    Biten videolar (16:9 YouTube)
- 05_thumbnail/  Thumbnail ve varyasyonları
- 06_shorts/     9:16 Shorts / Reels / TikTok kesitleri
